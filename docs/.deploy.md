# Déploiement Dashboard Vision AI + SIG Cadastre Algérien v1.0

## Hébergement options pour déployement production

### 1. Vercel (recommandé, gratuit avec limite)
```bash
# Installation CLI Vercel
npm install -g vercel-cli
vercel --prod

# Variables d'environnement dans dashboard/Vercel settings :
# GOOGLE_MAPS_API_KEY → Valeur de votre API Key Google Maps
```

### 2. Netlify (alternative gratuite)
- Connecter dépôt GitHub pour déploiement automatique continuous integration  
- Configurer environment variables via Netlify Dashboard UI  

### 3. Docker + Cloud provider (AWS/Azure/GCP)

Dockerfile :
```dockerfile
FROM node:18-alpine
COPY package*.json ./
RUN npm ci --only=production
COPY . .
EXPOSE 3000
CMD ["npm", "start"]
```

Build commande :
```bash
npx vercel build     # Build statique dashboard Vision AI + SIG
vercel deploy --prod
```

### 4. Node.js serverless hosting (Render/Azure)
- Upload package.json à Render.com ou Azure Container Instances
- Configurer secrets `GOOGLE_MAPS_API_KEY` via console provider UI  
- Environment variables propagation automatique après déploiement build
