# FAQ Dashboard Vision AI + SIG Cadastre Algérien v1.0

## Questions fréquentes API routes extraction géoréférencement

### Q : Comment démarrer le serveur dashboard Vue d'ensemble ?
```bash
npm install  # Premier lancement installation npm install  
npm run dev  # Mode développement http://localhost:3492
```

### Q : Où trouver ma clé API Google Maps ?
Obtenir une nouvelle clé depuis [Google Cloud Console](https://console.cloud.google.com/maps/credentials). La copier dans `.env` fichier comme :
```
GOOGLE_MAPS_API_KEY=your_api_key_here
```

### Q : Comment visualiser les résultats extraction Vision AI SIG ?
1. `npm run dev` pour lancer développement
2. Ouvrir `http://localhost:3492` dans navigateur  
3. Voir dashboard Vue d'ensemble districts extraits avec icônes détectées

### Q : Quels formats de fichiers croquis sont supportés ?
PNG (.png), JPEG/JPG (.jpg/.jpeg), GIF (.gif), TIFF (.tif/.tiff) pour extraction Vision AI + SIG.

### Q : Comment exporter les résultats d'extraction ?
Utiliser endpoint `GET /api/dashboard/export-data` avec paramètres format (`csv`, `json`, `tiger`) :
```bash
GET http://localhost:3492/api/dashboard/export-data?format=csv
```

### Q : Le dashboard fonctionne-t-il en mode hors ligne ?
Non, le dashboard API nécessite connexion internet pour calls API Google Maps Geocoding Places. Vue d'ensemble de districts sera disponible mais géoréférencement lat/lng demandera API keys connectées.

### Q : Comment ajouter un nouveau fichier croquis SIG au traitement batch ?
Mettre à jour tableau [data/tasks.json](../data/tasks.json) avec nouveaux fichiers, puis appeler POST `/api/dashboard/vision-batch`.
