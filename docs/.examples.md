# Exemples d'utilisation Dashboard Vision AI + SIG Cadastre Algérien

## 1. Appel API extraction batch croquis SIG PNG/TIFF/JPG

```bash
curl -X POST http://localhost:3492/api/dashboard/vision-batch \
  -H "Content-Type: application/json" \
  -d '{"files": ["16.08.05.png", "16.09.27.png"]}'
```

## 2. Récupérer liste fichiers extraction Vision AI + géoréférencement SIG

```bash
curl http://localhost:3492/api/dashboard/files?page=0&limit=10
curl http://localhost:3492/api/dashboard/stats
curl http://localhost:3492/api/dashboard/georef/files?page=0&limit=5
```

## 3. Utilisation client React composant `<FileCard>`

```tsx
import { FileCard } from './components/FileCard';

<FileCard 
  file={{
    fileName: "16.08.05.png",
    status: "done",
    icons: [{ type: 'mosque' }],
    landmarks: [{ name: 'stade', confidence: 0.9 }]
  }}
/>
```
