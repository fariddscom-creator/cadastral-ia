# Installation Dashboard Vision AI + SIG Cadastre Algérien v1.0

## Prérequis

### Système d'exploitation
- Windows / Linux / macOS
- Node.js 18+ et npm install

### Google Maps API Key (obligatoire)
Obtenir une clé API Google Maps Geocoding/Places : https://console.cloud.google.com/maps/credentials

Créer fichier `.env` à partir `.env.example`:

```bash
cp .env.example .env
# Éditer .env pour ajouter GOOGLE_MAPS_API_KEY=your_api_key_here
```

---

## Installation complète

```bash
cd D:/projets/cadst-ia          # Reprojet source Git clone ou téléchargement zip
npm install                     # Installer dépendances npm package.json next react sharp
cp .env.example .env            # Configuration API KEY Google Maps local
npm run dev                     # Démarrer serveur développement port 3492
```

### Test installation dashboard Vision AI + SIG v1.0

```bash
npm test                        # Exécuter tests unitaires extraction Vision AI  
npm run lint                    # Valider code ESLint TypeScript E6+TSX  
npm run build                   # Build production next build pour déploiement
```

---

## Accès après installation

### Mode développement (localhost)
Ouvrir navigateur `http://localhost:3492` pour visualiser dashboard Vue d'ensemble districts extraits

### Production (build complet)
```bash
npm run build                   # Build statique next build
npm start                       # Serveur production localhost:3000
```

---

## Déploiement cloud (Vercel/Netlify)

1. Installer CLI npm vercel netlify cli
2. `vercel --prod` ou `netlify deploy` pour déploiement automatique production  
3. Ajouter variables d'env Vercel/Netlify pour `GOOGLE_MAPS_API_KEY`
