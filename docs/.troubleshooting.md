# Guide Dépannage Dashboard Vision AI + SIG Cadastre Algérien v1.0

## Problèmes courants et solutions

### Erreur : `GOOGLE_MAPS_API_KEY non configuré`
```bash
cp .env.example .env
echo "GOOGLE_MAPS_API_KEY=your_api_key_here" >> .env
npm run dev
```

### Erreur : `Port déj\u00e0 utilisé (3000 ou 3492)`
Modifier `npm start` port dans `.env`:
```
PORT=3492
```

### Erreur : `TypeScript compilation failed tsc --noEmit`
Voir output errors, corriger fichiers sources `.tsx` avec types définis dans `types.d.ts`.

## Outils de debug dashboard Vision AI + SIG v1.0

### Browser DevTools
Ouvrir F12 → Console pour voir messages erreurs Node.js React hooks useEffect.

### Logs serveur
Afficher stdout du processus `npm run dev` pour déboguer API routes extraction géoréférencement.

### Google Maps API quotas dépassement
Obtenir nouveau API key avec quota accru depuis [Google Cloud Console](https://console.cloud.google.com).
